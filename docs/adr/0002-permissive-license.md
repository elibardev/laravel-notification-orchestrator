# ADR-0002 --- MIT license

Status: **Accepted**

## Context

The author intends the package to be usable in open-source, proprietary,
commercial and private applications with minimal licensing friction.

## Decision

Use the **MIT License**.

## Consequences

The package may be used, modified, distributed, sublicensed and
incorporated into proprietary applications subject to the MIT license
notice requirements.

The repository will identify the author/vendor as `elibardev`.
